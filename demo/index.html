01 / Architecture

ANATOMY OF THE CRAFT

Engineered down to the nanometer.

Every screen follows a deterministic typographic and architectural formula designed for zero visual ambiguity.

01 GEOMETRY

Hairline Planar Grids

Built using gap-px with container bg-line and child bg-bg. Eliminates doubled borders and renders authentic 1px drafting lines across all device display scales.

02 INDICATORS

Mechanical Odometer

Replacing the default browser scrollbar with a CAD-grade vertical percentage rail. Features rolling three-column numeric wheels, laser hairline needle, and section anchor jumps.

03 PHYSICS

Houdini CSS Morph

Registered @property declarations allow CSS custom properties to undergo mathematical color interpolation without repainting the entire DOM tree or suffering flickering states.

02 / Principles

BUILT FROM FIRST PRINCIPLES

Six rules for flawless execution.

Any agent adhering to these immutable constraints will produce websites of unassailable quality.

RULE 01

The Editorial Contrast

Never use pure sans-serif alone. Pair dense mechanical brutalist headings (Archivo) with humanistic italic serif accents (Instrument Serif).

RULE 02

Registration Corner Ticks

Every major bounded container and card gets 11px hairline crosshairs (.tick) placed precisely at corner intersections, referencing engineering blueprints.

RULE 03

Tactical Monospace HUD

Metadata, telemetry tags, section numbers, and specs must strictly utilize monospaced fonts with letter-spacing: 0.15em and uppercase transformation.

RULE 04

Instant Snappy Inversion

Interactive buttons and pills do not perform mushy shadow fades. They flip instantly via 120ms linear inversion of foreground and background colors.

RULE 05

Dual Authentic Palettes

Light mode is warm technical drafting paper (#f2f1ee). Dark mode is tactical obsidian and darkroom glass (#121316). No generic grayish tones.

RULE 06

Precision Ruler Scrollbar

The scrollbar is an interactive engineering tool with rolling mechanical digits, laser tick marks, and anchor points, gracefully falling back on mobile.
